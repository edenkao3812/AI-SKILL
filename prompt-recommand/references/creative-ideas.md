# 靈感點子類

Use for playful illustration, characters, collectibles, covers, and experimental branded creativity.

| ID | Archetype | Required slots | Recipe anchor |
| --- | --- | --- | --- |
| C1 | 四格漫畫 | premise, character, four beats, dialogue, comic style | Define setup, escalation, twist, and punchline panel by panel; keep the same character design throughout. |
| C2 | LINE 貼圖角色 | character reference, expression/action list, text, count | Q-version character with exaggerated readable emotions, clean silhouette, consistent proportions, transparent-background intent. |
| C3 | 旅行日記插畫 | destination, memories, objects, notes, palette | Notebook page combining map, ticket, handwriting, landmarks, food, and small scene sketches. |
| C4 | 黑膠唱片封面 | artist/title, genre, concept, mood, palette | Emotional low-saturation editorial photography or illustration with a strong square composition and restrained typography. |
| C5 | 漫畫封面設計 | title, volume, protagonist, world, action | Dynamic hero pose, dramatic environment, title and volume zones, clear adventure story tension. |
| C6 | 世界觀書封設計 | title/author, genre, world symbols, protagonist, mood | One iconic world image, atmospheric depth, mystery, and readable title/author hierarchy. |
| C7 | 復古雜誌封面 | era, topic, cover lines, language, palette | Large masthead, period-appropriate multi-column layout, nostalgic photography and colors. |
| C8 | 時尚雜誌封面 | model/reference, wardrobe, city, masthead/copy, mood | Editorial street photography, natural pose, real cover hierarchy, barcode/copy only when requested. |
| C9 | 寵物走出 IG 拍照框 | pet reference, account name, setting, motion | Pet steps through an original social-photo frame with wide-angle foreshortening, joyful expression, detailed fur, bright scene. |
| C10 | 黏土 Q 版角色踏出手機 | character/reference, outfit, themed mini-world, props | Collectible clay figure exits a large phone into a miniature diorama with playful floating social props and depth. |
| C11 | IG 精選動態封面 | brand reference, category list, icons, palette | Unified highlight-cover system for market info, products, colors, buying, prices, reviews, and other brand topics. |
| C12 | 扭蛋包裝風 | subject, variant poses, accessories, series name, labels | Original Japanese capsule-toy presentation: hero figure, machine/capsules, lineup, accessories, product-number and price zones, clean retail display. |

## Category guidance

- For C1, write each panel separately; do not ask the image model to infer the joke structure.
- For C2, ask for a complete expression/action inventory and output count before finalizing.
- For C4-C8, separate artwork from exact cover typography if text accuracy is critical.
- For C9-C12, keep real social-network, toy-company, or magazine branding generic unless the user supplies authorized assets. Preserve the visual grammar, not protected marks.
